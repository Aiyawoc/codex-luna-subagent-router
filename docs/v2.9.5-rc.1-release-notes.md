# Agent Router v2.9.5-rc.1 · 主动委派策略测试版

此版本为 **Release Candidate / Pre-release**，不是 Stable。基于 v2.9.4-rc.2 的 Decision Shadow 配置、Keychain 安全修复和诊断能力，同时包含两项本机开发功能：

- **`adaptive`（目标约30%）**：把同层同档的完整中等/深度工作包更早交给 SubAgent，分析性只读任务不再仅因多个并行任务而被主线程包办。
- **`adaptive_aggressive`（目标约50%）**：在上述规则上进一步允许浅层但独立、边界清晰、有可验证结果的工作包移交。机械查询和 micro 任务仍留给 Lead。
- **可选雷达 IQ 选型**：仅存在可立即派遣的 Worker 时才考虑读取模型评分。默认关闭；在确认第三方二次使用许可前不应开启。评分不能绕过原模型白名单、能力下限、预算、身份、并发或工作区权限。

**30%/50%是后续自然任务的观察目标，不是当前已实现的真实用量占比，更不是用量配额。** 本版本不会为了凑百分比创建 Worker、提高模型价格、降低验收标准或自动更改主 Agent。

## 获取与安装

Release 附带与系统匹配的完整包和对应 SHA256 校验文件（不要用 GitHub 自动生成的源码 ZIP 代替）：

| 平台 | 完整包 |
| --- | --- |
| macOS Apple Silicon | `router-2.9.5-rc.1-macos-arm64.tar.gz` |
| macOS Intel | `router-2.9.5-rc.1-macos-x64.tar.gz` |
| Windows x64 | `router-2.9.5-rc.1-windows-x64.zip` |
| Windows ARM64 | `router-2.9.5-rc.1-windows-arm64.zip` |

同页提供四份原生插件包、各自的 `.sha256` 及统一 `SHA256SUMS`。继续沿用当前完整 Skill 时使用 **`upgrade`**，不要同时启用同作用域的原生 Plugin 与完整 Skill。

**详细的本机 Agent 执行指引、离线策略对照、备份、配置验证、回退条件：** [v2.9.5-rc.1 安装升级与验收](https://github.com/Aiyawoc/codex-luna-subagent-router/blob/v2.9.5-rc.1/docs/v2.9.5-rc.1-test-guide.md)。

## 限制与验收

- 默认继续保留已有 `routing.json`、Keychain 引用、`automatic_checkpoints`、超时、hooks 与账本。**升级本身不会切换已有路由模式。**
- 允许使用 `configure_guided_install --delegation none --routing-scope user --routing-mode adaptive` 显式切换用户级路由，并保留其他配置；若存在项目级覆盖，必须以实际生效层为准。
- 在隔离测试 HOME 的 `adaptive`/`adaptive_aggressive` 规划中比较结果，不创建真实 Worker、不发送付费 API 请求。完成后再用有限自然任务观察采纳率、主/子净增量用量、返工与质量。
- 原开发提交已通过 **866 项源码测试**及 macOS ARM64 安装升级冒烟；本 RC 只有在精确源码提交的四平台发布流水线全部通过且校验完八份归档后，才标为公开候选。
- 当前可用数据不足以证明自然委派比例已达到30%/50%，也不能证明第三方 IQ 分数对代码任务成功率具有预测效力。

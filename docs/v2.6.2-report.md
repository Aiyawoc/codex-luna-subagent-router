# v2.6.2 — 一键数据简报命令

v2.6.2 只增加一个用户命令：`bin/router report`。它把现有三类统计读取整合为一次只读导出，不改变路由、hooks、token 采集、历史 `refresh`、outcome 校准或账本格式。

## 数据来源

`report` 直接复用现有 Python 统计 API，它们分别也是以下命令的底层实现：

- `route_advisor stats`：质量 outcome、pending receipt、校准建议和路由分布。
- `token_usage stats`：SubAgent 最新快照、模型/强度、覆盖状态和已知 token。
- `turn_usage stats`：已登记主轮次、主线程及安全关联子线程的本轮快照。

命令不会调用 `token_usage refresh` / `turn_usage refresh`，不会搜索其他 rollout，也不会因生成报告写入或改变 usage/outcome 账本。因此报告是“当前已保存统计的快照”，不是主动补全操作。

## 调用

```bash
# 默认：从当前工作目录解析 project scope；非项目目录回退 global scope
/path/to/router report

# 显式项目
/path/to/router report --project-root /path/to/project

# 仅 global
/path/to/router report --global-scope

# 所有已保存 scope；可能混合多个项目
/path/to/router report --all-scopes

# 指定输出根目录
/path/to/router report --output-dir /path/to/export

# stdout 只打印文件位置等生成元数据
/path/to/router report --json
```

`--all-scopes / --global-scope / --project-root` 互斥。默认输出根目录为：

```text
${CODEX_HOME:-$HOME/.codex}/state/codex-luna-subagent-router/reports/
```

每次运行创建 `UTC时间-scope/` 独立目录，避免覆盖旧报告。

## 输出文件

### `brief.md`

面向人的 Markdown 简报，包含：

- 生成时间、Router 版本和 scope；
- outcome 总数、pass/fail/partial、pending receipts 和可用校准建议；
- SubAgent 数、complete/waiting/partial/unavailable 覆盖率、已知 token 和按模型/强度汇总；
- 已登记主轮次、phase 分布、主线程/主子线程快照覆盖率和未关联 child 数；
- outcome 路由分布和常见诊断原因；
- 数据口径与限制。

### `data.json`

权威机器可读导出。保留统计 API 的嵌套结构和 token 原始整数，适合进一步分析或问题复现。导出时删除 `registry` / `usage_file` 的本机绝对路径；其它已由 stats 暴露的 session / turn / agent ID 会保留。

### `data.csv`

UTF-8 BOM CSV，便于 Excel / Numbers 直接打开。统一列覆盖：scope、session、turn、agent、parent、model、effort、status、时间、五项 token、reasons、outcome 和 count。`record_type` 区分：

- `outcome_summary`
- `outcome_route`
- `recommendation`
- `subagent`
- `turn_main`
- `turn_child`

CSV 是便于表格分析的扁平视图；不能表达的嵌套字段仍以 `data.json` 为准。

## 数据与隐私边界

- 不导出 prompt、回复正文、源码、原始 rollout 行或账号/密钥。
- session / turn / agent ID 会保留，报告文件仍属于本地诊断数据，不应无审查公开发布。
- `partial` / `unavailable` 不等于 0；报告不会猜补未知数据。
- token 是已知快照，不是账单、配额或实测节省金额；cached input 属于 input 子项。
- outcome 是 Lead 验收结果，token 完整度是另一维度，两者不能互相替代。
- `--all-scopes` 可能混合多个项目。普通项目简报优先在目标工作目录运行默认命令或显式 `--project-root`。

## 验收要求

1. 新命令只能读取现有 stats 数据，测试必须证明不会调用 refresh。
2. 空账本也能生成完整的三文件报告。
3. JSON 不出现本机 registry / usage 绝对路径。
4. CSV 至少覆盖 outcome、SubAgent、turn main、turn child；token 保留原始整数。
5. 四平台完整包使用随包 Python 执行 `report` 并验证三文件存在。
6. 现有 2.6.1 路由、统计、hooks 和安装测试全部继续通过。

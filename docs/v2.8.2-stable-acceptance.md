## Scope

Profiles support gpt-6.1-sol medium/high/xhigh/max. medium is narrowly opt-in through current Host support attestation; max is explicit-user-only. Default high/xhigh policy, Astra capability gates, luna_only and accounting remain intact. Plugin work belongs to 2.8.3 and is not part of this release.

Added regression coverage for all six-axis combinations, no automatic max, xhigh failure going to Astra directly, no max history downshift, no medium downshift of deep debug, independent review/luna_only isolation, exact profile IDs and required Host evidence.

Users must verify current Host support before supplying the new attestation.

With an actual Host-supported medium effort, compare a bounded medium-depth verifiable design with/without --sol-medium-supported. With missing support, do not set the flag. Verify max requires an explicit user request plus actual Host effort evidence. Do not fake receipts, rewrite historical data or let tools index the immutable installation directory.

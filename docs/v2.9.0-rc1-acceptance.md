# Agent Router v2.9.0-rc.1 — Field Acceptance

Date: 2026-10-04

## Scope

RC.1 freezes v2.9 implementation. It does not add routing authority.

Implemented areas:

- request-vs-receipt pricing granularity;
- Native Shadow same-execution identity binding;
- short-lock concurrent Token collection;
- unified read-only diagnostics;
- version-bound Host capability evidence;
- sanitized Codex app-server structured-event normalization;
- capability-gated Programmatic Tool Calling eligibility;
- fixed-workload benchmark store/comparison;
- fail-closed reserved OpenAI Decisions API provider boundary.

## Automated gates

The exact RC commit must pass:

- full unit-test suite;
- Manifest exact tracked-file coverage;
- Router Arena;
- Windows x64 complete package + plugin package smoke;
- Windows ARM64 complete package + plugin package smoke;
- macOS x64 complete package + plugin package smoke;
- macOS ARM64 complete package + plugin package smoke;
- SHA256 verification for all eight archives.

Synthetic package/event tests are not real Host acceptance.

## A. Read-only baseline

Run on one exact Codex Desktop Host version:

```bash
router diagnostics --project-root <repo> \
  --host-backend codex_desktop \
  --host-version <exact-version> \
  --verify-package --json
```

Confirm:

- package/runtime is healthy;
- Host capabilities remain unknown unless evidence exists;
- hook configuration does not claim Host trust or execution;
- diagnostics performs no transcript refresh or trust mutation;
- output contains no prompt/tool content or local absolute paths.

## B. Structured lifecycle and usage evidence

Use normal Host operation to obtain real supported app-server notifications.
Do not fabricate field evidence.

For observed events:

- normalize through `app_server_events`;
- record capability evidence only with explicit confirmation;
- lifecycle/usage support applies only to the exact backend + Host version;
- model-reroute events remain observational and never rewrite Router policy;
- thread lifetime usage and latest usage update remain distinct;
- structured usage is not request-level pricing evidence unless the Host supplies
  actual request boundaries.

If real event access is unavailable, record NOT VERIFIED rather than synthetic
proof.

## C. Programmatic Tool Calling

If the exact Host/version has real PTC support evidence:

- bounded multi-tool, read-only, predictable, structured-output work may be PTC
  eligible;
- semantic/adaptive judgment remains direct;
- approval-sensitive or write stages remain direct;
- citation/native-artifact preservation remains direct.

If PTC support is unknown, Router must use direct/native parallel fallback.

## D. Fixed workload benchmark

Freeze repository baseline, acceptance criteria, permissions, Host version and
fixture. Compare:

- `host_default`;
- `router_luna_only`;
- `router_adaptive`.

Record only known metrics using `benchmark_store record --confirm`. Unknown
metrics stay omitted/null.

Review with:

```bash
router benchmark_store compare \
  --backend codex_desktop \
  --host-version <exact-version> \
  --baseline host_default --json
```

A comparison may be review-eligible only with full evidence, no lower observed
success rate than baseline, and at least one comparable efficiency metric. It
never changes routing automatically.

## E. Existing lifecycle regression

Reconfirm at least:

- fresh Worker natural completion;
- completed Worker reuse with incremental accounting;
- Post-Stop historical freeze;
- real Host interrupt request followed by actual terminal state;
- unknown usage remains null rather than zero.

## Stable decision

RC.1 can advance to v2.9.0 Stable when:

1. all automated eight-package gates pass;
2. claimed real-Host capabilities have exact-version evidence, or remain
   explicitly unknown and unclaimed;
3. no PTC path bypasses approval/write/evidence boundaries;
4. benchmark evidence shows no unexplained quality regression for any Stable
   efficiency claim;
5. prior Desktop lifecycle/accounting behavior has no regression.

OpenAI Decisions API is not a Stable blocker while its official public
endpoint/auth/request/response contract is unavailable. The reserved provider
must remain disabled and network-inert.

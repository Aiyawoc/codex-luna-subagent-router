# v2.9.5-dev.1: Delegation-time IQ comparison

Base: v2.9.4-rc.2 (`6a26f1a7520ba8676630ec371cdae9dca850764f`). This is a development candidate, not a published Release and not a production install.

User request: fetch only the CodexRadar model-intelligence table after deciding a SubAgent is useful, then consider the information when selecting its model/effort. The first implementation attaches to the existing `route_advisor plan` path **after** readiness checks and **before** planning/decision telemetry is recorded. It does not ask an extra LLM to rank candidates.

## Implemented

- Fixed read-only summary endpoint, bounded subprocess HTTP fetch, five-minute reuse/cooldown, independent batch-age checks, strict protocol and numeric/provenance validation, no redirects or task/credential transmission.
- Whole ready wave shares one snapshot. No ready Worker means no fetch. The public summary is the only feed; reset, quota and speed radar are not included.
- Baseline classification and local validated outcomes constrain candidates. Explicitly authorized ceilings prevent silent expensive upgrades; score/cost/time are an experimental 60/25/15 composite, with quality/cost floors and no material change on a tie.
- Observation versus bounded selection modes, explicit setup helper, per-plan `--no-radar`, and independent read-only statistics in `report`.
- New selection receipts correlate with existing plan_id. Base Lead, counts, scope, dependencies, grouping and wave health semantics remain unchanged.

## Not claimed

- Data-use authorization has not been obtained by this implementation. Integrators must confirm usage with the provider; no feature is automatically enabled for the current installation or future users.
- Benchmark rank does not prove private-project capability, actual model identity, subscription cost savings or persistent availability. Current Host validation and real acceptance remain mandatory.
- No new model family or effort is approved. Terra, older models and Sol max remain outside new automatic choices; the default does not pay for higher tiers just because the table ranks them higher.
- Four-platform CI, release publication and a production upgrade are separate later gates. The normal Decision Engine stays Shadow-only.

See `skills/codex-luna-subagent-router/references/radar-selection.md` for configuration, precise gates, utility formula and cache/error behavior. Tests use synthetic public-score fixtures only; real site measurements are kept outside Git in the user's ignored audit directory.

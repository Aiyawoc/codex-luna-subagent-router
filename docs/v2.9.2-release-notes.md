# Agent Router v2.9.2 Stable

正式版本包含 **7 项可保留的安装选择**，新增可选决策供应商引导和官方 **OpenAI Decisions API Shadow** 适配，同时纳入 v2.9.1 的稳定性修复。本版本保留原有的 Luna / Sol / Astra 自动 Worker 路由，**不改变用户当前的主 Agent**。

## 新增与修复

- **第七项引导**：在全新安装或有未确定选项的升级中询问是否开启决策模型，选择 OpenAI Decisions、TypeSafe System One、本地 JEV /ask 或兼容 HTTP。默认关闭；选择过关闭或已经明确配置的旧 JEV 不会反复询问。以后可随时重新打开配置引导。
- **安全 API Key**：系统凭据库隐藏输入（macOS Keychain、Windows Credential Manager），或只保存环境变量**名称**；不将 Secret 写入 Router 配置、Git、命令参数或账本。旧网络惰性的 OpenAI 占位配置在未经再次确认前不会变成付费调用。
- **官方 Decisions 接口**：固定 `POST https://api.openai.com/v1/decisions`，目前使用 `gpt-6-luna`；校验 `choice`、`predicate`、`score` 的结构化结果、概率、拒绝与错误。无凭据／额度不足／超时等仅让本次 Shadow 不可用。
- **观察而非自动授权**：Decisions 仍只在有证据和必要 checkpoint 时作为 Shadow 采集；实际路由、权限、Worker 数量和主 Agent 的订阅模式不受它控制。
- **2.9.1 稳定性修复**：迟到的 Worker terminal/accounting、超长记录有限读取、Windows 文件描述符释放、四／可选六事件 hook 生命周期和模型来源盘点。当前新自动候选与校验保持 GPT-6 Luna、GPT-6.1 Sol、GPT-6 Astra；历史旧型号只用于兼容读取。

## 安装与升级

在本 Release 页下载与系统及 CPU 匹配的**完整包**和紧邻的 `.sha256` 文件。不要使用 GitHub 自动生成的 Source Code ZIP 代替完整包。

| 平台 | 完整包 |
| --- | --- |
| macOS Apple Silicon | `router-2.9.2-macos-arm64.tar.gz` |
| macOS Intel | `router-2.9.2-macos-x64.tar.gz` |
| Windows x64 | `router-2.9.2-windows-x64.zip` |
| Windows ARM64 | `router-2.9.2-windows-arm64.zip` |

还提供对应的 4 份 `router-plugin-2.9.2-<platform>` 本地 marketplace 插件包；**不要同时激活两套拥有相同作用域的 Router Skill 和 Plugin**。默认插件仍只包含四项 hooks；可选六事件 variant 不会在默认 Release 中自动开启。

按 `SHA256SUMS` 与各归档旁的 `.sha256` 校验完整性，再在解压后的完整包运行：

```bash
./bin/router doctor --verify
./bin/router inspect_guided_install --json
# 检测到旧安装时先明确选择 upgrade 或 fresh
./bin/router install --global --install-mode upgrade
```

**不要在有活跃 Codex Worker 时强制更新，也不要删除旧账本或自行修改 Host 信任数据库。** 安装后根据缺失选项完成七问。以后单独调整决策提供商：

```bash
./bin/router configure_decision_engine --scope user --guided
```

上面向导需要交互终端。无 TTY 的 Agent 可以只配置 `--credential-source env --api-key-env OPENAI_API_KEY`，密钥须由用户安全地传入真正运行 Router 的进程；Terminal 临时 export 不保证 Desktop 可读。

## 验收与限制

正式发布工作流在与 `main` 精确一致的提交上重新运行源码测试、Router Arena、四平台完整包与默认插件的安装、升级、hook、迁移、回退验证，并核对八个归档的 SHA256。完整验收说明见 [v2.9.2 Stable Acceptance](https://github.com/Aiyawoc/codex-luna-subagent-router/blob/v2.9.2/docs/v2.9.2-stable-acceptance.md)。

**不宣称**当前 Codex Desktop 已真实验证 Keychain 授权、native plugin 加载、Decisions API 在真实子线程执行路径中的自动触发、Host 计费归属或与 Host default 的成本／质量／延迟比较收益。这些能力按精确 Host 和版本另行采集现场证据。用户此前直接调用过 Decisions API，但该连接测试不等于新版 Router 全链路 Host 验收。

参考 [CHANGELOG.md](https://github.com/Aiyawoc/codex-luna-subagent-router/blob/v2.9.2/CHANGELOG.md) 与 [Provider setup](https://github.com/Aiyawoc/codex-luna-subagent-router/blob/v2.9.2/docs/v2.9.2-decision-onboarding.md)。

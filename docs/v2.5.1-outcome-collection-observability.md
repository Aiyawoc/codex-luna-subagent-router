# v2.5.1 — Outcome Collection, Observability & Workload Planning

## 已核对的基线

main 为 v2.5.0（721af18528ec211b46c70b77cf5e9892e52f9571）。恢复分支 v2.5.1-outcome-collection 的 8f589b094a77709ab7835d024cf8eaac33b4088b 已有设计文档，功能未完成。

用户三条记录仅说明该文件记录稀少，不能仅凭集中时间证明所有其他 Worker 漏记；本版让登记但未结算的情况可观察。

## P0 采集

begin 建立只含 metadata 的回执，冻结 scope、family、六轴、请求 model/effort；task ID 只保存哈希。finalize 要 Lead 验收，未知实际身份、环境阻塞、取消、early stop、Lead 实质返工均 partial。只有可信 observed model/effort 匹配且有结果验证时才记 verified outcome。

同回执幂等、防重复计数、冲突报错、文件互斥锁与 fsync；坏行/旧数据只报告，不静默清除。close 前尝试记录，失败披露后仍及时关闭线程。没有引擎 hook：完全未 begin 的 Worker 不在可观察覆盖范围。

## Scope 与统计

从命令 cwd 探测 Git 顶层；显式项目根优先，非 Git 可显式指定；global-scope 用于无项目与旧记录。finalize 使用回执，不跟随后来的 cwd。全局安装不等于全局样本；不自动迁移用户已有 global 行。

stats 无需六轴；默认全部 scope，可筛当前项目。显示结果、模型、effort、scope、最后写入、pending、旧无 ID 行、重复/坏行、稀疏 bucket、可用建议和阈值缺口。不将建议称为实际覆盖，不虚构费用节省。

## 两级复用

A 保留原同 scope/family/六轴/policy、90 天、2 次同模型或 3 次安全跨 tier 的门槛。

B 要求同 scope/六轴/policy，至少 5 个唯一回执、至少 2 个 family；只在可验证、非高风险、非 architecture 场景同模型下降一个 effort 档。失败否决，不跨模型、不利用旧无 ID 行。阈值是启发式，不是已证明的成功率；不凑廉价试跑样本。

## 新增：Astra high 的整组任务分配

v2.5.0 Advisor 是单目标决策，不提供 sibling assignment。新增 plan 批量规划：同类任务统一分类；共享上下文可 batch；独立且有净收益的任务按有效容量先创建再 wait；依赖、读写冲突或 Lead 前置任务则等待。

Astra 主用 Luna 不等于故障；普通任务应保持经济路线，复杂因果分析仍考虑 Sol。昂贵 Lead 不为保持忙碌亲自重复廉价同类任务，保留任务必须有具体关键路径/上下文/权限/外部副作用原因。不强制多模型、不强制开满三线程。

Worker 单波上限仍 min(3, Codex 显式上限)；需要扣除实际已打开线程。默认一个向上高级 Worker，不是所有向下 Luna/Sol 只能一个。plan 不执行 spawn，也不绕过权限、精确路由与 RoutePlan 2.1。

## 验证边界

完整仓库已合入本版改动，并在 Python 3.13.5 下通过全部 153 项本地测试，包含并发进程、CLI、scope、幂等、未知身份 partial、旧 JSONL、TTL/policy、A/B 校准、批量依赖规划及完整安装升级。另补齐依赖图合并成环、Lead/运行中 Worker 的读写冲突、有效并发上限等集成边界。

发布必须通过完整 Manifest 和远端跨平台 CI；记录与实机检查步骤见 `v2.5.1-release-validation.md`。本地测试不等于 Codex Desktop 真实派遣、身份观测或全部 Worker 采集覆盖率验证；不得仅据单元测试宣称这些行为已经在用户环境通过。

## 后续实机验收

升级完整包并保留 adaptive + conservative。两项独立 bounded 实现应两个 Luna 同波；共享小任务可一个 Worker；深度因果任务推荐 Sol；记录失败不占住线程。检查 stats 的 pending 与 partial 原因，不能只看总行数或成功率。没有真实 token 计量前不报告节省百分比。

# Agent Router v2.8.0-rc.2 — Route Economics Unknown-Cost Acceptance

> RC.2 is a narrow bug-fix candidate based on the RC.1 local acceptance report. Feature freeze remains in effect.

## RC.1 finding

RC.1 represented an empty Route Economics scope as:

```json
{
  "outcome_records": 0,
  "matched_receipts": 0,
  "estimated_attempts": 0,
  "estimated_usd": 0.0
}
```

and `router report` rendered the value as `$0.000000`.

That conflated two different states:

- no receipt-bound sample can be estimated;
- at least one sample was estimated and the known estimate is exactly zero.

Router's existing accounting rule is `unknown != 0`, so RC.1 failed this acceptance criterion.

## RC.2 required semantics

When no attempt can be estimated:

```json
{
  "estimated_attempts": 0,
  "estimated_usd": null
}
```

The same rule applies to each route entry with zero estimated attempts.

`router report` must render unknown estimated token cost as `-`, not `$0.000000`.

When at least one receipt-bound attempt is successfully estimated, `estimated_usd` remains numeric and the existing pricing/calculation behavior is unchanged.

## Scope freeze

RC.2 changes only missing-value representation and report rendering for Route Economics.

It must not change:

- `gpt-6-luna → gpt-6.1-sol → gpt-6-astra` routing;
- Execution Shape decisions;
- Desktop token accounting;
- Agents API shadow authority;
- cost-review candidate thresholds;
- pricing rates or long-context rules;
- Decision Shadow behavior.

## Release gates

The exact RC.2 commit must pass:

- complete Manifest verification;
- full Python test suite;
- deterministic Router Arena;
- portable runtime build/smoke on Windows x64, Windows ARM64, macOS x64 and macOS ARM64;
- prerelease package/hash verification before `v2.8.0-rc.2` publication.

Local field re-test should specifically reproduce the RC.1 failing commands on an empty global/project scope:

```bash
router route_economics --global-scope
router report --global-scope --output-dir <dir> --json
```

Expected:

- `estimated_attempts = 0`;
- `estimated_usd = null`;
- report shows `Estimated token cost | -`;
- no missing/unknown value is silently converted to zero.

## Test shape

Use one clean Host conversation/session with two real user parent turns.

### Turn A
- install/upgrade to rc.3;
- use project routing_mode=luna_only and Decision Engine off;
- run one bounded Luna-sufficient task that naturally creates one Worker W;
- record real Worker identity/model/effort and child turn ID;
- let W complete and let the parent turn end naturally;
- after the real Stop, confirm Turn A is sealed, end_boundary_known=true, and child snapshot is complete/known as available.

### Turn B
The user sends a new real message in the same Host session, asking a narrow follow-up in the same module/workflow that remains Luna-sufficient.

Require:
1. RoutePlan minimum capability is Luna.
2. Runtime follow-up naturally targets the exact same Worker W identity.
3. No new SubagentStart is required for PASS; this is the lifecycle under test.
4. Parent transcript for Turn B records structured Interacted activity for W.
5. Reused child SubagentStop binds a new non-null child_turn_id to Turn B.
6. Turn B child_boundaries[W].baseline = exact_cursor.
7. Turn B end_boundary_known = true after child completion.
8. Turn B child snapshot exists and contains only the interval after Turn A's frozen child cursor.
9. Worker lifetime may grow, but Turn A counts/boundary/child_turn_id remain unchanged.
10. Normal inherited paginated SessionMeta does not cause conflicting_session_headers.
11. Unknown values remain null, never invented as zero.
12. If a new receipt exists, persisted receipt interval and finalize JSON token_usage agree.

## Safety requirements

Do not fake SubagentStart/Stop, parent turns, Token counters, parent activity, or ledgers. Do not edit source during acceptance. Do not manually set active=true. The only valid ownership proof for a no-start reused child is the real current-parent Interacted activity plus the exact reused-child cursor and the real SubagentStop.

If the Host does not naturally reuse W, report NOT VERIFIED. If reuse occurs but child_turn_id/end boundary/snapshot remains absent, report FAIL.

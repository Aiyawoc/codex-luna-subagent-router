# Agent Router v2.8.1 — Stable Acceptance

Date: 2026-10-03

## Scope

v2.8.1 is a focused guided-install release. It does not change v2.8 routing authority, Execution Shape policy, model family, Native shadow authority, Route Economics authority, or Cost Review authority.

## Guided install contract

Preflight now checks the selected install target before package replacement:

- no existing target installation -> install mode is `fresh`;
- existing target installation -> the user must explicitly choose `upgrade` or `fresh`;
- existing target + no choice -> installer refuses replacement;
- no existing target + `upgrade` -> installer refuses and requires `fresh`.

`upgrade` preserves/migrates explicit configuration and historical ledgers and asks only missing/stale choices.

`fresh` replaces the complete package and re-runs all six guided choices. It does not silently delete historical ledgers, backups, or unrelated user files.

Global and project targets are detected independently. A global installation does not make a new project-scoped target an upgrade.

## Six guided choices

1. Standing automatic-delegation authorization
2. Automatic routing mode
3. Maximum concurrent SubAgents
4. Verified Outcome Calibration
5. Token accounting and completion summaries
6. Default-mode structured questions

Each inventory question states what the option controls before asking for a value.

Fresh configuration has explicit off semantics:

- `--delegation off` removes only Router-managed authorization blocks;
- `--request-user-input disable` writes an explicit false setting;
- legacy `none` remains a compatibility value meaning “leave the current setting unchanged”.

Decision Shadow, Agents API Shadow, Native authority readiness, Route Economics, and Cost Review remain Advanced / Observability and do not add mandatory setup questions.

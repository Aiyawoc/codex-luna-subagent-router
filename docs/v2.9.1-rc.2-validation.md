## 范围与依据

基于 2.9.0 定点脱敏证据定位的两类问题实现修复：子线程终止记录晚到与生命周期收尾不同步；旧超长 CommandExecution 记录阻断新轮次读取。附加只读模型来源诊断和最小 hook 字段状态。没有把私有日志、真实会话 ID 或原始证据提交到 Git。

实机补采标识的环境为 Desktop 26.1013.40934 / build 20770、内置引擎 0.163.0-alpha.10.2、macOS ARM64；这证明证据采集环境，不等于 RC.2 已在该 Desktop 的真实 hook 中运行。

设计与限制详见 Core [统计收尾与证据诊断](../skills/codex-luna-subagent-router/references/accounting-closure.md)。

## 关键验收边界

- 结束记录只按精确子轮次观察；旧 partial 不因计数相等直接提升。
- 生命周期重新读取，不复制区间计数；复用、封存、中断和并发更新不串账。
- 超长已知工具记录完整流式校验后才能推进；未知/损坏/超预算记录保守失败。
- configured/requested/observed 分离；当前磁盘配置不是历史有效配置；没有 Router 关联回执继续 unknown。
- 缺路径样本只补未来的最小字段状态，不猜类别、不排除历史分母。
- 新 reader/cache 使旧缓存失效，但不迁移或改写原 usage/turn/outcome 账本。

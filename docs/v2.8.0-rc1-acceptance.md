# Agent Router v2.8.0-rc.1 — Release Candidate Acceptance

> Feature freeze begins at RC.1. This candidate is intended for local installation, Desktop regression testing, and real Agents API shadow acceptance. Agents API native evidence, trace data, route economics, and cost-review candidates remain non-authoritative.

## Frozen scope

- Automatic Worker family: `gpt-6-luna → gpt-6.1-sol → gpt-6-astra`.
- Historical `gpt-6-sol` remains read-compatible only and is not a new automatic Worker route.
- Execution Shape remains `local_serial / local_parallel_tools / subagent`; Host capability mapping does not alter planner semantics.
- Codex Desktop rollout/hooks accounting remains the current production accounting path.
- Agents API Turn/lifecycle/usage adapter, read-only transport, OTLP trace summary, shadow ledger and readiness gate remain shadow-only.
- Route economics and `cost_review` remain observational; `automatic_override=false` and production `route_advisor` is unchanged.
- Decision Shadow remains optional, fail-open, non-authoritative and default-off.

## Source acceptance

RC.1 must pass on its exact release commit:

- complete `MANIFEST.sha256` verification;
- full Python test suite on supported CI versions/platforms;
- deterministic Router Arena audit;
- portable bundle build + shipped-runtime smoke on Windows x64/ARM64 and macOS x64/ARM64;
- immutable RC tag/release creation only after all package jobs pass.

Local pre-publish baseline on Python 3.13.15 before version freeze:

- 465 / 465 tests PASS;
- Manifest 157 / 157 PASS;
- Router Arena PASS.

The final RC commit is re-run after the version/docs/workflow freeze; the release workflow is the publication gate of record.

## Desktop acceptance

Use a clean or representative Codex Desktop install and verify:

1. install/upgrade succeeds and `router doctor --verify` passes;
2. installed version reports `2.8.0-rc.1`;
3. `adaptive` routes Sol work to exact runtime ID `gpt-6.1-sol`;
4. `gpt-6-sol` is not emitted for a new automatic Worker;
5. `luna_only` remains Luna-only;
6. `local_parallel_tools` and `subagent` behavior show no v2.7 planner regression;
7. existing token accounting preserves `unknown != 0`, exact turn boundaries and sealed historical turns;
8. `router report` is read-only and reports Native Host Shadow / Route Economics without refresh or authority changes.

## Agents API shadow acceptance for Stable

RC.1 may be published before this real-host evidence exists. Stable must not promote Agents API evidence merely because RC.1 ships the adapters.

For Stable review, use real existing Agents API sessions/subagents and collect:

- native usage versus Router canonical usage on controlled turns, including late-arriving usage;
- completed lifecycle;
- cancelled/interrupted lifecycle;
- interrupt-request followed by natural completion;
- trace summary timing/overlap where trace export exists.

Record only sanitized observations with `host_transport shadow --record`. The conservative readiness gate defaults to:

- usage: at least 10 clean consistent evidence keys, with no latest divergence/inconclusive/truncated/invalid evidence;
- lifecycle: at least 3 resolved terminal evidence keys, with no unresolved interrupt request.

`eligible_for_review` opens human review only. `automatic_promotion` remains false.

## RC decision

Publish `v2.8.0-rc.1` when the exact RC commit passes source/package gates above.

Do not label the same commit Stable solely because RC packaging passes. Stable remains a later explicit release decision after RC field testing and the required real Host review.

# Agent Router v2.7.0-rc.4 — Final MultiAgentV2 Post-Stop Acceptance

> Feature freeze remains in effect.  
> RC.1 Sol Lead H3 is PASS. RC.2/RC.3 already proved paginated metadata compatibility, exact cursor carryover, same Completed Worker reuse, Turn A freezing, and safe end-boundary freezing.  
> RC.4 validates only current MultiAgentV2 persisted parent activity and the resulting post-Stop interval recovery.  
> Decision Engine remains off.

## Clean test shape

Use one new Host conversation/session and project `routing_mode=luna_only`.

### Turn A
- install/upgrade to rc.4 and verify package/doctor;
- run one bounded Luna-sufficient task that naturally creates exactly one Worker W;
- record real Worker identity/model/effort;
- let W and the parent turn end naturally;
- confirm Turn A is sealed with a known exact child end boundary and child snapshot.

### Turn B
The user sends a real next message in the same Host session with a narrow same-module Luna-sufficient follow-up.
- naturally reuse the exact same Worker W;
- require `baseline=exact_cursor`;
- no new SubagentStart is required;
- Host parent activity should contain real `Interacted` for W;
- do not fake hooks/activity/ledgers;
- let the parent turn end naturally.

Do not require a final child snapshot before the Turn B final reply has finished; parent Stop/activity flush may complete afterward.

### Turn C — read-only post-Stop observer
The user sends one more real message in the same session.
- create/reuse no Worker;
- read Turn B only;
- Turn B must be stopped/sealed;
- `baseline=exact_cursor`;
- exact end boundary known;
- child snapshot for W present;
- child snapshot counts represent only Turn B's new interval, not W lifetime;
- Turn A interval/boundary remain unchanged;
- unknown stays null;
- normal inherited SessionMeta does not cause `conflicting_session_headers`.

`child_turn_id` is useful diagnostic evidence, but its absence alone is not a Stable blocker when same Worker identity, parent Interacted activity, exact start/end cursors, and the resulting interval snapshot establish safe attribution without guessing.

## MultiAgentV2 compatibility requirement

The acceptance is specifically for the current persisted shape:
`event_msg → item_completed → item.type=SubAgentActivity`.

Only `Started/Interacted` establishes current-turn ownership. A `Completed`-only activity must not activate an otherwise historical Worker.

## Stable decision

READY FOR v2.7.0 requires:
- same Worker W naturally reused in Turn B;
- Turn B baseline exact_cursor;
- Turn C sees Turn B exact end boundary and child snapshot;
- snapshot is interval-only;
- Turn A stays frozen;
- no new Core regression.

If W is not naturally reused, report NOT VERIFIED. If W is reused but post-Stop Turn B still lacks an exact interval snapshot, report FAIL.

# Agent Router v2.9.3 Stable: macOS Keychain Crash Hotfix

这是 v2.9.2 的兼容性热修复，直接针对首次真实 API 决策验收暴露的 **macOS Keychain SIGSEGV**。v2.9.2 的 Decisions API、安装第七问、供应商选择、凭据来源及 Shadow 权限都保留，不需要重新配置或重新输入 API Key。

## 修复内容

在 v2.9.2 中，系统找到 Keychain 条目之后，本地 `SecKeychainItemFreeContent(data, None)` 将第一个参数误用为数据指针；而 Apple 的真实签名为 `SecKeychainItemFreeContent(attrList, data)`。这导致进程在发出网络请求之前崩溃。

本版采用 `SecKeychainItemFreeContent(None, data)` 并统一处理**读取与已有凭据覆盖写入**两条路径；仅当数据指针有效时释放，独立释放 Keychain item 引用，并明确 C 参数与返回类型。

新增 7 项针对此问题的单元测试，包括空缓冲区、异常和无匹配条目。测试不使用用户 Keychain，不发起任何付费 API 请求。

## 获取与升级

请从本 Release 页选择平台对应的完整包和 `.sha256` 校验文件，而非 GitHub 自动生成的源码 ZIP：

| 平台 | 完整包 |
| --- | --- |
| macOS Apple Silicon | `router-2.9.3-macos-arm64.tar.gz` |
| macOS Intel | `router-2.9.3-macos-x64.tar.gz` |
| Windows x64 | `router-2.9.3-windows-x64.zip` |
| Windows ARM64 | `router-2.9.3-windows-arm64.zip` |

同时提供四平台原生插件发行包和 `SHA256SUMS`。遵循原有的 **升级安装 (upgrade)** 方式，保留选择、密钥、账本和用户自行安装的权限；不要同时启用两套拥有相同作用域的 Plugin/Skill。

升级前先结束活跃 Codex 会话，解压并运行：

```bash
./bin/router doctor --verify
./bin/router inspect_guided_install --json
./bin/router install --global --install-mode upgrade
```

安装完成可在本机安全的独立账本上**仅发送一次** Decisions Shadow 请求复验。请勿在聊天中粘贴 API Key、不要读取或导出用户 Keychain Secret。如果之前的 Keychain 权限已授予，不需要再次创建 Key。

## 尚待现场验证

修复的 ABI 与 Apple 文档一致，单元和完整包 CI 验证读取／写入路径的模拟 native 函数。**这不是实际 Keychain 凭据读取通过的证明。** 真实 macOS Desktop 下的 Keychain 授权、Router API Request、`predicate`→`noul`、Shadow ledger 和独立费用归属，仍以用户下一次受控验收为准。

原验收期间还观察到一条来源未能证实的 `outcomes.jsonl.receipts.jsonl` 新记录：它与 Decisions 测试的合成任务不匹配；本版本不修改或回滚该生产账本。

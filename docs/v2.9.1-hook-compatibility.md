# Agent Router v2.9.1-rc.1：Hook 兼容性收口

日期：2026-10-22。
源码基线：v2.9.0，commit `3d85e6153e7949fd986d029599b45bc0447f614f`。
开发分支：`upgrade/v2.9.1-hook-compat`。

## 本轮范围

本轮落实升级计划的第一阶段：兼容性、轻量结束事件、运行诊断、显示设置和回退边界。不是 v2.10 原生事件总线改造，也不是全量重新设计路由策略。

| 项目 | 实现 |
|---|---|
| 事件兼容 | 默认四事件保留；Interrupt / SessionEnd 需独立确认后启用，timeout=3，同步、小写入、不读 transcript。 |
| 中断归属 | 按精确 scope/session/turn 记录；冻结已知轮次快照，晚到 Stop 和新轮次不补入旧账。 |
| 会话结束 | 只保留会话级证据，不假定 turn_id 或完成结果。 |
| 健康诊断 | 每个 scope/事件记录当前安装与版本的 received/handled/failed；诊断失败不阻止普通统计。 |
| 配置诊断 | 同时盘点 JSON、内联 TOML、用户/项目层，显示重复来源和显式本地策略限制。 |
| 自动摘要 | silent/brief/detailed 与统计开关独立；已有选择保留，新开启默认 silent。 |
| 插件 | 四事件默认包不变；显式六事件验收包使用不同文件名，四事件包不接受未声明事件配置。 |
| 安全与回退 | 旧 usage/turn/outcome schema 不变；不写信任、不新增权限、不下载 hook 运行时依赖，不删除历史。 |

详细配置与限制见 [Hook 兼容性参考](../skills/codex-luna-subagent-router/references/hook-compatibility.md)。现场操作提示词见 [本机 Agent 验收](v2.9.1-local-acceptance-prompt.md)。

本轮恢复后的自动化验证见 [RC.1 验证记录](v2.9.1-rc.1-validation.md)。六事件变体使用 `tools/smoke_plugin.py --lifecycle-hooks` 独立验收，覆盖启用前无写入、终止事件幂等、诊断、停用与回退；四平台工作流也加入该检查，但不会把此变体自动加入默认 Release 资产。

## 正确理解执行证据

配置存在、处理器收到 stdin、当前 Desktop 真正触发、Host 信任以及最终用量完整，是五件不同的事。handler receipts 可以由本地直接调用产生，所以它们不自动提升 `host_hook_trust`、`host_event_execution` 或 Host capability。没有终止事件证据的执行状态仍为 unknown；Stop 不是业务验收通过证明。

中断事件不携带完整用量。当前策略选择保留可信旧快照，不把停止后才读到的无边界累计值当成本轮最终计数。这会保留 partial/unavailable，是已知覆盖限制，不是完整统计声明。

## 不再重复客户端职责

本轮没有新增线程执行器、权限审批器、账户用量面板、客户端插件 UI 或后台常驻进程。模型策略、任务边界、质量回执和项目级归因保留在 Router；Host 执行与信任仍由客户端管理。

App Server 归一化适配器与 Host capability 接口仍按 v2.9.0 的证据边界运行；未建立桌面端私有订阅，也未把账户 usage 当作任务 ledger。后续 v2.10 必须先验证受支持的实际接入点，才考虑原生来源优先和日志兼容回退。

## 实机验收及发布边界

仓库测试和在临时 CODEX_HOME 中执行真实 bundled Python 只能证明代码、包和合成事件链路。它们不能替代当前 Desktop 的 marketplace 加载、信任审查、真实事件触发及 UI 验收。

本轮不修改操作者正在使用的 Codex 安装、信任数据库和生产统计账本。所有安装/升级/停用/回退 smoke 必须使用隔离临时目录。原有 `.serena/` 和 `.uv-bootstrap/` 不纳入提交。

RC 保持候选状态。macOS x64、Windows x64/ARM64 的真实平台测试、最新 Desktop 现场验收及真实工作负载对比均不能由当前 macOS ARM64 的成功推定。完成这些证据之前，不发布 Stable、不声称统计完整或成本下降。

## 下一阶段

先完成当前 Desktop 的四事件与可选两事件实机验收，再决定默认安装方式。只有证明可访问同一实际执行的原生事件，才推进 v2.10 统一输入与归因；同一区间仅有一个计数权威来源，其他来源只能补证，不能相加。

随后复用已有八类工作负载对比 `host_default / router_luna_only / router_adaptive`，把 Lead、Worker、重试和整合成本一起计入。没有收益的任务回到 Host 原生路径，不为增加委派数量而扩充规则。

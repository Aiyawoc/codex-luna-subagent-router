# v2.6.0 — Private Python Runtime Delivery

## Scope

Ship CPython 3.13.15 in four complete platform packages (Windows x64/ARM64, macOS Intel/Apple Silicon). Source Git contains only code, lockfiles and build configuration. Windows uses the official embeddable archive; macOS uses python-build-standalone 20260901 install_only_stripped. Runtime downloads happen only at maintainer build time and are checked against pinned SHA256 values.

## Milestones

- M0: branch and PR before implementation/tests; source baseline recorded.
- M1: native launchers, runtime validation, package integrity, transactional installer and reviewed hook migration.
- M2: four platform builds and native tests using the actual bundled interpreter, including empty PATH and Unicode/space paths.
- M3: Agent-first installation docs, manifest, authorization-gated release workflow and verification report.

## Compatibility

No system Python, PATH, config.toml, routing.json, unrelated Agent profiles, outcome/usage ledger or hook trust storage is modified by package installation. Complete bundles reject fallback to a system interpreter. Old hook definitions become pending under question 6; no automatic trust. Previous packages are retained for rollback. Upgrade from a separate extracted bundle; do not overwrite a running installed interpreter in-place.

Luna/Sol/Astra routing, evidence thresholds, concurrency schema and token parsing semantics are unchanged. The previous log-boundary/multiple-session-header diagnostics are not claimed to be repaired by this runtime work.

## Verification boundaries

See PR #20 for exact commit, local/CI results and package sizes. Native runner tests are not Codex Desktop real-account acceptance. No merge/tag/Release is authorized by this implementation PR. macOS signing/notarization and actual downloaded-file quarantine behavior require separate target-machine validation.

## 交付复核补充

macOS 的 install-only 包省略了 full 包顶层元数据。构建时额外从同一固定 PBS 提交取得 20 份顶层许可文本，逐份验证 Git blob 身份，并保存 SHA256 和来源；这些文件随包离线交付，不在 hooks 运行时下载。许可集合保留上游所有顶层声明，不代表每个可选组件都实际链接。

安装器补充暂存目录创建失败时释放安装锁的回归测试。原生 smoke 输出完整 unittest 结果，以区分通过和平台限定跳过。

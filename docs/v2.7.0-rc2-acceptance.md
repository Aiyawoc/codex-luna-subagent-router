> Feature freeze remains in effect.  
> RC.1 Gate 1 (Sol Lead H3 fresh-wave Materialization / Runtime Health) is already PASS and must not be repeated.  
> RC.2 validates only the cross-parent-turn reused Worker boundary/accounting path plus minimal installation regressions.  
> Decision Engine remains off.

## Why this must use two real user turns

A local Agent executing inside one parent turn cannot truthfully manufacture a second user parent turn. The final gate therefore has two stages separated by a real user message:

1. **Turn A** creates and completes one reusable Worker, then the parent answer finishes and the Host Stop hook persists/finalizes Turn A.
2. **Turn B** is a new user follow-up in the same Host session/workflow and may naturally reuse the same Completed Worker.

Do not synthesize a second parent turn, edit ledgers, invoke fake hooks, or fabricate Token counters.

## Stage A — Establish the frozen boundary

Use a bounded reasoning task that naturally delegates to one Worker and leaves a useful follow-up for the same module/problem family.

Require before finishing Turn A:

- real Materialized Worker identity W is known;
- actual Worker model/effort is observable from runtime/usage evidence;
- no `conflicting_session_headers` caused by inherited paginated parent metadata;
- Worker W completes normally.

After the real parent Stop has run, read only:

```bash
router turn_usage stats --global-scope --json
# or the exact project scope used by the Host
```

Record the Turn A row and its sanitized `child_boundaries[W]`:

- `child_turn_id` is present;
- `end_boundary_known = true`;
- baseline is `fresh` for a newly spawned Worker or otherwise safely classified;
- do not expose cursor offsets, hashes, transcript paths, or transcript content.

Also record Turn A's persisted child snapshot/known interval when available.

Only then proceed to the next real user message.

## Stage B — Natural reuse in the next parent turn

The user sends a follow-up that naturally benefits from Worker W's retained context. Follow normal Router policy; do not force reuse if the Host/Router rejects it.

If the exact same Worker identity W is reused:

1. Turn B must have a real new parent turn identity.
2. Turn B's `child_boundaries[W].baseline` must be `exact_cursor` (the frozen Turn A child end boundary), not lifetime-zero or guessed.
3. Turn A remains frozen; its Token counts/end-boundary diagnostics must not expand after Turn B activity.
4. Worker lifetime may increase, but Turn B child snapshot contains only the new interval.
5. If a receipt is finalized for Turn B, finalize JSON and persisted receipt binding must expose the same per-attempt interval rather than Worker lifetime.
6. Unknown fields remain null; missing evidence is never converted to zero.
7. A late `SubagentStop` from another child turn ID must not backfill Turn A.

If the Host does not naturally reuse W, report **NOT VERIFIED**, not PASS and not a Router failure.

## Paginated rollout compatibility check

For Worker W, confirm the real usage snapshot no longer fails merely because inherited parent `SessionMeta` exists before the child own-history boundary. Actual post-boundary conflicting identity must still fail closed.

Expected evidence:

- model/effort is verifiable when the Host emitted it;
- `conflicting_session_headers` is absent for the normal inherited-prefix layout.

## Minimal regression checks

Confirm only:

- installed version = `2.7.0-rc.2`;
- package SHA256 and `doctor --verify` pass;
- upgrade preserves existing routing/hooks/ledgers/unrelated profiles;
- Decision Engine remains off;
- `router report` is readable;
- no unexpected non-GPT-6 automatic Worker is observed.

Do not rerun Gate 1, Decision Shadow, Router Arena, fuzz, or the full Alpha suite locally.

## Stable decision

`v2.7.0` is READY only when:

- Stage A produces a verifiable exact frozen child boundary;
- Stage B naturally reuses the same Worker identity;
- Turn B uses `exact_cursor`;
- Turn A remains frozen;
- Turn B/receipt usage is interval-only;
- no new Core regression is observed.

Otherwise report FAIL for an observed violation or NOT VERIFIED when the Host never provides the required natural reuse.
